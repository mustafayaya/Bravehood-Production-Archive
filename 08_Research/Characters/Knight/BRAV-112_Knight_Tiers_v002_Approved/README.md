# BRAV-112 — Knight Tier Concepts v002 (Approved)

Approved by Mustafa on 2026-09-26 as the visual direction for the Knight armour progression. This package supersedes the v001 concepts for production direction; the earlier tier-specific v001 branches remain immutable research history.

## Approved tier direction

- **T1 Militia:** brown vertically quilted jack, green padded sleeves and trousers, sparse mismatched iron protection, visible cross-stitched field repairs, and a segmented nasal cap.
- **T2 Man-at-Arms:** fitted forest-green canvas brigandine with regular rivet rows, limited mail, exposed vambraces and greaves, and a repaired kettle hat.
- **T3 Dungeon Knight:** exposed articulated plate, charcoal trousers, a belt-wide front-only green tabard, banner-free back, a darker replacement left pauldron, and an open bascinet.
- **T4 Vanguard:** old hand-fluted heirloom plate, narrow full-length green surcoat, substantial aged leather, restrained tarnished-brass inlay, and a repaired open comb helm.

## Package contents

Each tier contains four approved PNG sheets:

1. Front armour view
2. Back armour view
3. Three-quarter armour view
4. Helmet design sheet

All views use the BRAV-111 Knight body and camera language. Helmets remain open-faced. This is an approved 2D concept package; it does not contain production 3D assets or rigged equipment.

## Production handoff

BRAV-114 may use this package as the source for unrigged 3D generation. Expected later equipment separation is torso, legs, helmet, and separate cloth geometry for the T3 tabard and T4 surcoat. Rigging and Unity integration require a separate reviewed step.

File integrity hashes are recorded in `qa/SHA256.json`.
